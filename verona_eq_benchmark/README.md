# Verona Resurrected EQ Benchmark

A comprehensive emotional intelligence evaluation framework for "Verona Resurrected," adapted from the EQBench3 methodology used for evaluating Large Language Models.

## 🧠 Project Overview

This project demonstrates how to adapt AI benchmarking methodologies to evaluate emotional intelligence in creative writing. Using principles from EQBench3, we analyze the psychological depth, emotional complexity, and empathetic understanding demonstrated in Carlo's Gothic reimagining of Romeo and Juliet.

## 🏆 Key Results

**Overall EQ Score**: 79.5/100  
**Assessment**: Strong (Top-Tier LLM Equivalent)  
**Performance Tier**: Matches GPT-4 and Claude-3.5-Sonnet levels

## 📊 Evaluation Framework

### Five-Dimensional Assessment

1. **Emotional Complexity** (0-20): Sophistication of emotional dynamics
2. **Character Psychology** (0-20): Depth of psychological insight
3. **Empathy & Understanding** (0-20): Character emotional awareness
4. **Moral Reasoning** (0-20): Ethical emotional reasoning complexity
5. **Literary EQ** (0-20): Author's skill conveying emotions to readers

### Key Passages Evaluated

- **"Corrupted Love Reunion"** (Chapter 2): 89/100 - Supernatural love transcendence
- **"The Apothecary's Scientific Rationalization"** (Chapter 1): 83/100 - Moral complexity
- **"Friar Lawrence's Moral Crisis"** (Chapter 3): 73/100 - Ethical responsibility
- **"Romeo's Protective Rage"** (Chapter 5): 73/100 - Transformed nature

## 🎯 Methodology

### Adapted from EQBench3

1. **Scenario Identification**: Extract emotionally complex passages
2. **Multi-dimensional Scoring**: Apply 5-category evaluation framework
3. **Character Analysis**: Evaluate psychological depth and development
4. **Comparative Benchmarking**: Measure against LLM performance standards

### Literary EQ Advantages

- 📚 Narrative depth over time
- 🎨 Atmospheric emotional expression
- 🧠 Direct psychological access
- 💭 Complex moral ambiguity
- 🌟 Thematic integration across chapters
- 🎪 Genre-enhanced emotional resonance
