Setup GitHub Actions Workflow

This repository includes a GitHub Actions workflow that can automatically convert your markdown files. Here's how to use it:

Method 1: Fork this Repository

  1. Fork this repository to your GitHub account
  2. Replace the markdown files in the markdown_yfd/ folder with your own
  3. Commit and push your changes
  4. The workflow will automatically run and create converted DOCX files
  5. Download the artifacts from the Actions tab

Method 2: Manual Workflow Trigger

  1. Go to the Actions tab of this repository
  2. Select "Convert Markdown to DOCX" workflow
  3. Click "Run workflow" to trigger manual conversion
  4. Download the resulting DOCX files from the workflow artifacts
Note: To use the GitHub Actions method with your own files, you'll need to either fork this repository or create your own repository with the workflow file.

📖 About This Tool

This converter prepares manuscript markdown files for import into ProWriting Aid by:

  • Standardizing chapter headings: Converts to H1 format with consistent "Chapter N:" structure
  • Optimizing document structure: Uses only Heading1 + Normal styles for perfect ProWriting Aid compatibility
  • Adding proper spacing: Includes empty paragraphs after chapter headings for correct parsing
  • Creating clean documents: Zero page breaks ensure smooth chapter detection
ProWriting Aid Ready: Converted files are optimized for ProWriting Aid's chapter detection and will import cleanly with proper structure.
